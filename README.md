# Guía de investigación EC2

Aplicación web estática para orientar a los estudiantes en la elaboración del segundo avance de investigación.

## Tecnologías

- HTML
- CSS
- JavaScript con módulos
- Google Sheets publicado como CSV, de manera opcional

No requiere Java, base de datos, npm ni servidor propio.

## Ejecutar en Visual Studio Code

1. Abre en Visual Studio Code la carpeta `guia-investigacion-ec2`.
2. Instala la extensión **Live Server**, si aún no la tienes.
3. En el Explorador de archivos de Visual Studio Code, haz clic derecho en `index.html`.
4. Selecciona **Open with Live Server**.
5. La página se abrirá en el navegador.

Es recomendable utilizar Live Server porque los navegadores pueden restringir la carga de archivos cuando se abre `index.html` directamente desde el disco.
